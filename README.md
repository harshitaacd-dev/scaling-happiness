# Dissertation: AI screening tools, data transparency and the gender data gap

Master's research paper (ISS, Erasmus University Rotterdam). It audits how transparent AI breast and cervical
cancer screening tools deployed in India are about their data, scored against the 29 STANDING Together recommendations.

## Folders

- [`literature-search/`](literature-search/): reproducible search for papers and trial registrations on each tool (2 Nov 2026).
